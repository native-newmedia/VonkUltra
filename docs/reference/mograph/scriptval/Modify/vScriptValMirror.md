## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Mirror Axis | Dropdown | `X` | Axis to mirror across. Options: X, Y, Z. |
| Axis Pivot | Float | `0` | Position of the mirror plane. |
| Keep Original | Integer | `1` | Outputs the original points together with the mirrored points. |
| Input | DATATYPE | `—` | Data to process. |
