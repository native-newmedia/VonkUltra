# vFileSystemFileOpen

Opens a file This node will open the "Source File" using the operating system's default file handler. The exact program launched is defined by the file extension.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Source File | Text | `—` | Path to the file to open with the OS's default handler for its file extension. |
| Show Input | Integer | `1.0` | Reveals the wire for the Source File connection in the Flow view. |
