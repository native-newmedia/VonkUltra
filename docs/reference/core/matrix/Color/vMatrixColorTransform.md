## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Affect Canvas | Integer | `1.0` | Extends the colour transform beyond the current DoD by also setting the background canvas colour — useful when a later Crop node expands the image beyond its original size. |
| Matrix | Text | `—` | 4×4 colour transform matrix applied to each pixel's RGBA. |
| Show Input | Integer | `1.0` | Reveals the wire for the Matrix connection in the Flow view. |
| Input | Image | `—` | Source image to transform. |
