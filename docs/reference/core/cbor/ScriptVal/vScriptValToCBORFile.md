## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| ScriptVal | ScriptVal | `—` | The ScriptVal object to write out as CBOR. |
| File | Text | `—` | Destination path for the saved `.cbor` file. Hidden until Show Input is enabled. |
