## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Input | Text | `—` | JSON array text to slice. |
| Start | Integer | `1` | 1-based index of the first element to keep. |
| End | Integer | `-1` | Index of the last element to keep. -1 means the last element, -2 the second-to-last, and so on. |
| Show Input | Integer | `0.0` | Reveals the wire for the Input connection in the Flow view. |
