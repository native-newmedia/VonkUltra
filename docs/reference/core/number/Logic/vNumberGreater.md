# vNumberGreater

Compares two numbers to see if Term 1 is greater than Term 2 A zero (false) or one (true) based number is returned from the comparator operation.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Term 1 | Float | `0` | First value to compare. |
| Term1Separator | Float | `—` | A UI separator, not a real setting. |
| Term 2 | Float | `0` | Second value to compare — Output is 1 if Term 1 is greater than Term 2, otherwise 0. |
| Show Input | Integer | `0.0` | Reveals the wires for the Term 1/Term 2 connections in the Flow view. |
