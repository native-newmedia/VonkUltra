## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Radians | Float | `0` | Cosine ratio (-1 to 1) to compute the arc cosine of. Output is in radians. (The field is labeled "Radians" in the source fuse, which is inaccurate — the input here is a ratio, not an angle.) |
| Show Input | Integer | `0.0` | Reveals the wire for the Radians connection in the Flow view. |
