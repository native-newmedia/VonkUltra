# vTextSubStripRight

Strips a trailing substring of a string The "Strip" text field is used to define the text you would like to remove from the (right side) of the input text data that is connected to the node. This type of text editing would sometimes be called removing a trailing postfix element from a string.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Text | Text | `—` | The source text to strip a trailing substring from. |
| Strip | Text | `—` | The postfix text to remove from the right side of Text. |
| Show Input | Integer | `1.0` | Reveals the wire for the Text connection in the Flow view. |
