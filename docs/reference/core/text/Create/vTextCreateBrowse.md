# vTextCreateBrowse

Creates a Fusion Text object with a file browser dialog This node is used to create filepath based Text data type content. The Browse button displays a file picker dialog.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Text | Text | `—` | The filepath text — click Browse to fill it in via a file picker dialog. |
| Expand PathMaps | Integer | `0.0` | Converts a relative PathMap-based filepath into an absolute path on the output. |
