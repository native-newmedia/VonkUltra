# vTextFromASCII

Converts an ASCII code number to text The "Number" control is used to enter an ASCII code value. The result is a single character placed inside a text data type based output.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Number | Integer | `0` | ASCII code value to convert into its corresponding character. |
| Show Input | Integer | `1.0` | Reveals the wire for the Number connection in the Flow view. |
