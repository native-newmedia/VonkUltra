# vTextCaseRandom

Changes the case of a Fusion Text object in a random fashion A Text based input of "hello world!" would be converted to an output like "hellO WoRlD!".

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Text | Text | `—` | Text to convert — each letter's case is randomized. |
| Show Input | Integer | `0.0` | Reveals the wire for the Text connection in the Flow view. |
