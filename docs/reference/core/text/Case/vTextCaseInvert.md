# vTextCaseInvert

Inverts the case of a Fusion Text object A Text based input of "Hello World!" would be converted to "hELLO wORLD!". Every uppercase letter in the output becomes lower case, and every lowercase letter becomes an uppercase letter.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Text | Text | `—` | Text to convert — uppercase and lowercase letters are swapped. |
| Show Input | Integer | `0.0` | Reveals the wire for the Text connection in the Flow view. |
