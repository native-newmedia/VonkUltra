# vTextCaseAlternate

Alternates the case of a Fusion Text object A Text based input of "hello world!" would be converted to "hElLo wOrLd!" where every 2nd letter is formatted as a capital letter.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Text | Text | `—` | Text to convert — every 2nd letter becomes uppercase. |
| Show Input | Integer | `0.0` | Reveals the wire for the Text connection in the Flow view. |
