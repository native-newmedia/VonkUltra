# vTextCaseSentence

Converts the case of a Fusion Text object to sentence A Text based input of "hello world!" would be converted to "Hello world!" with the initial letter in each sentence having a capitalized letter.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Text | Text | `—` | Text to convert — capitalizes the first letter of each sentence. |
