## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Gradient | Gradient | `—` | Fusion's native gradient-bar control — add, move, and colour stops directly in the Inspector. |
| Gradient Interpolation Method | FuID | `—` | Interpolation style used between colour stops, set via Fusion's own gradient bar UI. |
| Show Input | Integer | `0.0` | Reveals the wire for the Gradient connection in the Flow view. |
