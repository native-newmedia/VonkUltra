## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Point | Point | `—` | Point whose X/Y/Z coordinates are converted to a Vector. |
| Columns | Integer | `3` | How many of the point's components to keep, from the left (X, then X/Y, then X/Y/Z). Default 3 keeps all of X/Y/Z. |
| Show Input | Integer | `1.0` | Reveals the wire for the Point connection in the Flow view. |
