## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| Input | Text | `—` | XML text to query. |
| Index | Integer | `1` | 1-based position of the element to retrieve when the XML contains repeated/sibling elements. |
| Show Input | Integer | `0.0` | Reveals the wire for the Input connection in the Flow view. |
| Get Key | Float | `—` | Attempts to rename this node using a `Key` value, but this node has no Key input (only Index) — a leftover copy-paste from vXMLGet's identical button. Clicking it renames the node to `xml_nil` rather than anything useful. |
